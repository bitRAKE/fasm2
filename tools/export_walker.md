This tool is a zero-execution static analysis utility for Windows Portable Executable (PE) modules designed to illuminate the complex "Loader Dynamics" of a library's public interface. It safely maps the target binary as an image resource to parse its export table, distinguishing between executable code and read-only data exports while recursively traversing forwarded functions across dependency chains—including API Sets and virtual modules—to identify their ultimate destination. By integrating with the system's debugging framework, it resolves ordinal-only identifiers into human-readable symbol names and semantically tags exports with their architectural roles (such as COM factories, service entry points, or internal telemetry hooks), providing a transparent and complete map of the module's external contract without executing its initialization code.

Every hop in the export chain has an RVA and ordinal. Optionally, they have a name and/or resolved symbol for the RVA. All these can serve to document and verify the trajectory.
